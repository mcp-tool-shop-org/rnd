# NVIDIA Agent Skills mirror

A pinned, searchable snapshot of [NVIDIA/skills](https://github.com/NVIDIA/skills):
skill names, descriptions, lanes (from upstream `skills.sh.json`), and links to
each SKILL.md at the synced commit. Skill bodies are not copied; follow the URL.

- `source.json`: upstream repo, family prefixes, lane file (human-owned)
- `catalog.json`: generated by `python -m rnd catalog sync nvidia-skills`; never hand-edit
- `review.json`: studio fit (`direct` / `adjacent` / `general`) and notes (human-owned)

Refresh with `python -m rnd catalog sync nvidia-skills`, then check whether
`review.json` needs notes for new skills (`rnd catalog list --fit` shows rated
items; unrated new families inherit nothing until reviewed).
