## Summary

The CUDA C++ Core Compute Libraries shipped with CUDA 13.4: faster scans on Blackwell, C++ standard parallel algorithms on the GPU, simpler CUB calls, batched warp reductions, and ahead-of-time compilation from Python.

## Key points

- Warp-specialised `cub::DeviceScan` reaches up to about 92% of memory bandwidth on Blackwell (previously about 50%).
- Standard parallel algorithms in `cuda::std` (copy_if, find_if, merge, reduce, transform, scan) with the `cuda::execution::gpu` policy.
- Single-call APIs across CUB device-wide algorithms.
- `WarpReduceBatched` reduces several datasets inside one warp at once.
- `cuda.compute` 1.1 can compile CCCL algorithms ahead of time for several architectures on a build machine with no GPU.
- In 13.4 Update 1, Thrust, CUB and libcu++ are each at 3.4.3, including Windows on Arm.

## Studio relevance

Arrives passively when PyTorch and engines rebuild against it. The 92% figure is most likely measured on data-center Blackwell; do not assume it holds on the 5090.
