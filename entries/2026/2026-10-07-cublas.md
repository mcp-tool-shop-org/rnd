## Summary

NVIDIA's GPU implementation of the BLAS linear-algebra routines, shipped in the CUDA Toolkit. It has sibling libraries for flexible GEMMs (cuBLASLt), multi-GPU dispatch (cuBLASXt) and device-side use inside your own kernels (cuBLASDx).

## Key points

- Covers BLAS levels 1–3: vector ops, matrix-vector, matrix-matrix.
- Uses Tensor Cores automatically where it can.
- Column-major storage by default (the Fortran convention), so row-major C/C++ data needs a transpose trick or the operand order swapped.
- State lives in a `cublasHandle_t` (workspace, stream, settings).

## Studio relevance

Underneath almost every model we run; the practical takeaway is the column-major convention when reading GPU matrix code.

## Claims

- [unverified] cuBLAS implements all 152 standard BLAS routines.
- [disputed] "cuBLAS uses 1-based indexing by default": its functions take ordinary pointers, and 1-based indexing appears only in Fortran-compatibility helper macros. Column-major is the real convention.
