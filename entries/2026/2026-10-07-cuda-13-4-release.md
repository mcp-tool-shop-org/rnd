## Summary

CUDA 13.4 is the toolkit release that brings first-class Windows on Arm support (aimed at RTX Spark devices), an early developer preview for the Rubin data-center architecture, Multi-Process Service V3, more CUDA Tile programming features, PTX ISA 9.4 and CCCL 3.4. It also includes a set of compiler, runtime and packaging changes; see [[2026-10-07-cuda-13-4-developer-experience]].

## Key points

- Windows on Arm: compiler and runtime support for arm64 Windows machines.
- Rubin preview: lets kernel and library authors target the next data-center GPU before hardware ships ([[2026-10-07-nvidia-rubin-architecture]]).
- MPS V3: GPU sharing between processes, now with a scriptable CLI, TOML configuration and cgroup integration (Linux containers).
- CUDA Tile and cuTile Python grow; dependent (programmatic) launches let kernel setup overlap ([[2026-10-07-cuda-tile-programming]]).
- PTX ISA 9.4 ([[2026-10-07-ptx-isa-9-4]]) and CCCL 3.4 ([[2026-10-07-cccl-3-4]]).
- A low-level Compute Fabric Transport API for communication-library authors ([[2026-10-07-cuda-compute-fabric-transport]]).

## Studio relevance

Already installed on the Robot rig (nvcc 13.4). Nothing to upgrade: ComfyUI's torch (cu130) runs the 5090 fine and no 13.4 change is called out for consumer Blackwell. MPS is Linux-only, so it matters at most on rented offrig pods. See [[2026-10-07-robot-rig-cuda-stack]].
