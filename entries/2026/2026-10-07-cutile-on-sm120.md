## Summary

The tile-kernels page of the CUDA Programming Guide does not say which architectures cuTile supports. Before planning any tile-kernel work on the Robot rig, establish whether consumer Blackwell (compute capability 12.0) is supported.

## Key points

- Cheapest answer: install `cuda-tile` in a scratch venv and run a one-kernel smoke test on the 5090.
- Otherwise: the cuTile Python package README or release notes should list supported architectures.

## Studio relevance

Answered 2026-10-19: yes, it runs here ([[2026-10-20-cuda-python-on-5090]]). Argon's exploration (2026-10-20) cites
release notes on tileiras compiler crashes for some sm_120 kernels [unverified], so cuTile stays out of critical
paths for now.

## Claims

- [verified] cuTile (`cuda-tile` 1.7.0) runs on compute capability 12.0: a vector-add kernel ran correctly on the RTX 5090 (via: the smoke rung on the studio rig, R&D, 2026-10-19; [[2026-10-20-cuda-python-on-5090]])
