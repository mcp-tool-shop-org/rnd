## The facts

- Argon (Gemini, through Antigravity on a consumer Google AI Ultra plan) wrote three pieces of code:
  - aspire-si #144: a determinism table for attention kernels;
  - aspire-si #145: two validation-gate changes;
  - role-set #55: a variety axis for generated puzzle items.
- That code runs inside the pipeline that **generates and checks training data** for the studio's own small local
  verifier model (Qwen3-8B with LoRA). The verifier isn't sold or offered to anyone. **No Gemini-written text enters
  the training data;** only the code runs.
- **The current reading** (R&D's, and your earlier answer): the Google Terms of Service (effective 2026-07-30) list
  among abuses "using AI-generated content from our services to develop machine learning models or related AI
  technology". Antigravity's terms incorporate it. Read literally, this reaches code used to build a model's training
  data, so the code was ruled out and is being rewritten.
