We follow a fixed list of sources: NVIDIA, CUDA, Ollama, OpenVINO, PyTorch, ComfyUI, llama.cpp, NeMo Relay, PAIR and Claude Code. This week, 26 October to 1 November, turned up 67 new items across 18 sources.

## What we acted on

- **Claude Code 2.1.311 to 2.1.316.**
  - A headless run that fails at startup used to exit with code 0 and print nothing. It now prints the error and exits with code 1.
  - A new permission setting makes the file-writing tools refuse paths outside the working directories, in every permission mode.
  - Hooks written in PowerShell now block correctly in more cases.

  Our agent harnesses run Claude Code headless and read its exit code, so we are adding a check for the new failure exit before their next run, and looking at the write block for our pinned settings. See the [Claude Code releases](https://github.com/anthropics/claude-code/releases).

## Worth knowing

- **NeMo Relay 0.11.0** (stable). We plan to use it to trace agent runs, and our notes on it now cover 0.11.0. What changed:
  - local hooks verify TLS;
  - tool checks fail closed by default;
  - traces continue through Claude Code hooks;
  - it needs Node.js 24.13.1 or newer.

  See [NeMo Relay 0.11.0](https://github.com/NVIDIA/NeMo-Relay/releases/tag/0.11.0).
- **PyTorch 2.15.0.**
  - CUDA 13.2 is the default wheel, with 13.4 alongside.
  - `torch.compile` works on Python 3.15.
  - NVFP4 decoding is faster on Blackwell GPUs.
  - `import torch` can no longer be re-run in the same process.

  We'll check the 13.4 wheel against the open cuBLAS bug on our watchlist before using it. See [PyTorch 2.15.0](https://github.com/pytorch/pytorch/releases/tag/v2.15.0).
- **Liquid AI LFM3.** These are small models now supported by Ollama, including a 1.7B text model built for tool calling. Their licence is Liquid AI's own: commercial use isn't licensed for a company with annual revenue of 10 million US dollars or more. So for us they are research-only.
- **ComfyUI 0.43.0** adds the first part of dynamic VRAM key-value caches and faster decoding for some models.
- **NVIDIA's skills catalogue** added several skill sets, including DGX Spark, NeMo Fabric, a Nemotron voice agent, TileGym and Run:ai. We mirror the catalogue in our library.
- **NVIDIA's DeepSeek-V4.1-Flash NVFP4 checkpoint** is MIT-licensed, but at about 429 GB it is far beyond a single 32 GB card.

Skipped this week: about 30 items across llama.cpp builds, skills metadata, Docker news and NVIDIA posts outside our fields.

## From our own bench this week

[Issue 35](/rnd/newsletter/issue-35/) covered the week's work. We also filed licence notes for the judges in our judge bake-off and for local evaluation subjects. We added the CUDA 13.4 cuBLAS grouped-matrix-multiply bug on Blackwell to our watchlist.
## How the watch works

A script lists what is new on a versioned set of sources, and a scout reads the primary notes and ranks each item. We check every acted-on item against its source before publishing.
